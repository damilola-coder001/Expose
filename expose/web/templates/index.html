SCORING METHODOLOGY v1.0

How Security Score is Calculated

Expose evaluates security posture using an objective, deterministic 100-point scale across 9 canonical security categories. Deductions are only applied for verified empirical findings, scaled by severity and confidence.

Category Weights

Scoring Principles

  • Empirical Evidence Only: Neutral observations and positive security controls receive zero point deduction.
  • Confidence Weighting: Confirmed issues incur 100% of their base deduction; potential indicators incur reduced deductions.
  • Clamped Boundaries: Category scores never fall below 0 or exceed 100 points.
  • Transparent Philosophy: A score of 84/100 reflects externally observable controls, not an absolute guarantee against compromise.
